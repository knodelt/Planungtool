# Demo-Datenhaltung

Diese Version enthält ausschließlich neu angelegte fiktive Datensätze und eine eigenständige Browser-Speicherung. Die früheren Backend-Module und komprimierten Anwendungssnapshots sind nicht enthalten. Es gibt keine konfigurierten Datenbankkennungen oder Zugangsschlüssel.

Die Demo ist nicht für vertrauliche Informationen gedacht. Das offen dokumentierte Passwort `demo` dient nur zum Vorführen der Bedienung. Importierte Dateien werden lokal verarbeitet; eine aktive Excel-Dateifreigabe kann beim Bearbeiten einer selbst importierten Datei einen Schreibvorgang auslösen. Eingebaute Beispielteile werden ausschließlich im Browser bearbeitet.
